레슨 1

새 세션(홈페이지 작업방)으로 들어가기

📱 스마트폰 Claude 앱

  1. Claude 앱을 열어요.
  2. 왼쪽 위 ☰ 메뉴를 눌러요.
  3. Code(클로드 코드)를 눌러요.
  4. 목록에서 “홈페이지 작업 (poianopks.github.io)”을 눌러요.
  5. 아래 입력창에 할 일을 써요. 예: “홈페이지 첫 화면 보여줘”

💻 PC 웹

  1. 크롬에서 claude.ai/code 에 들어가요.
  2. 왼쪽 목록에서 “홈페이지 작업 (poianopks.github.io)”을 눌러요.
  3. 입력창에 할 일을 써요.
레슨 2

다시 예전 대화방(a)으로 돌아오기

📱 스마트폰 Claude 앱

  1. ☰ 메뉴 → Code로 들어가요.
  2. 목록에서 “컴퓨터 접속 세션”을 눌러요.
  3. 예전 대화가 그대로 나와요. 화면을 위로 올리면 처음 대화부터 볼 수 있어요.

💻 PC 웹

  1. claude.ai/code 에 들어가요.
  2. 왼쪽 목록에서 “컴퓨터 접속 세션”을 눌러요.
궁금해요

❓ 자주 하는 질문

Q. 새 세션에 들어가면 예전 대화가 지워지나요?
아니요. 두 세션은 따로 저장돼요. 언제든 오가며 볼 수 있어요.
Q. 새 세션의 클로드는 예전 대화를 아나요?
몰라요. 필요한 내용은 새 세션에 다시 알려주세요.
Q. 목록에서 세션이 안 보여요.
이 페이지 위쪽의 “이 방 열기” 버튼을 누르세요.
Q. 채팅 메뉴에서도 보이나요?
아니요. 일반 채팅 목록이 아니라 Code 목록에서 찾아야 해요.

✅ 한 줄 요약

☰ 메뉴 → Code → 세션 이름을 누르면 그 방으로 들어가요.
예전 대화는 “컴퓨터 접속 세션”에 그대로 남아 있어요.
